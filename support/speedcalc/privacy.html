SpeedCalc 개인정보 처리방침
기준일: 2026년 11월 13일 · 적용 버전: SpeedCalc 0.6.0

SpeedCalc는 개인정보를 수집하거나 개발자가 운영하는 서버로 전송하지 않습니다. 광고, 분석 SDK, 사용자 추적 기능이 없으며 앱 계정이나 로그인이 필요하지 않습니다.

수식, 결과, 변수와 최근 기록은 Mac에서 처리합니다. 최근 2,000개 기록과 최근 결과 10개 등을 포함한 세션을 로컬에 저장합니다. 화면 모드, 글꼴, 언어 등 설정도 로컬에 저장합니다. 기록 내보내기는 사용자가 선택한 위치에 텍스트 파일을 만듭니다. 해당 위치의 클라우드 동기화 여부는 사용자가 사용하는 서비스와 설정에 따릅니다.

복사 명령은 결과 텍스트를 시스템 클립보드에 넣습니다. 자동 복사는 기본적으로 꺼져 있으며 설정에서 켤 수 있습니다. 붙여 넣은 내용은 계산 입력으로 사용합니다. 시스템 기능을 통한 클립보드 공유는 macOS 설정에 따릅니다.

계산 기록을 지워도 변수와 최근 결과 참조는 유지됩니다. 내보낸 파일은 기록 지우기로 삭제되지 않습니다. 로컬 앱 데이터와 내보낸 파일은 사용자가 제거할 때까지 남을 수 있으며 앱 삭제만으로 모든 로컬 데이터가 지워지는 것은 아닙니다.

이메일로 문의하면 회신을 위해 이메일 주소와 제공한 내용을 사용합니다. 민감한 계산 정보는 보내지 마세요. 이메일 처리에는 이메일 제공자의 정책도 적용됩니다. 지원 웹사이트는 GitHub Pages에서 제공합니다. 사이트에 별도의 분석 도구나 추적 스크립트를 넣지 않습니다. GitHub는 서비스 보안을 위해 방문자의 IP 주소를 기록하고 보관합니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.

SpeedCalc Privacy Policy
Reference date: November 13, 2026 · Applies to SpeedCalc 0.6.0

SpeedCalc does not collect or transmit personal data to developer-operated servers. It includes no advertising, analytics SDKs or user tracking. No app account or sign-in is required.

Expressions, results, variables and recent history are processed on your Mac. The app saves its session locally, including up to 2,000 history entries and the most recent 10 results. Appearance, fonts, language and other preferences are stored locally. History export writes a text file to a location you select. Synchronization of that location by a cloud service depends on your own service settings.

Copy commands place result text on the system clipboard. Optional automatic copying is off by default and can be enabled in Settings. Pasted content is used as calculator input. Clipboard sharing through system features is governed by your macOS settings.

Clearing calculation history keeps variables and recent result references. Exported files are not removed by clearing history. Local app data and exported files remain until you remove them; deleting the app alone may not remove all local data.

If you contact support by email, your email address and the information you provide are used to respond. Do not send sensitive calculation data. Email handling is also subject to the email provider's policies. The support website is hosted on GitHub Pages. We add no analytics tools or tracking scripts to this site. GitHub logs and stores visitor IP addresses for service security. See the GitHub Privacy Statement for details.
