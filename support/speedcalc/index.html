Mac용 수식 계산기 · macOS 13 이상

문의: bobaepapa@gmail.com
SpeedCalc 버전, macOS 버전, 문제가 발생한 수식과 재현 순서를 알려 주세요. 민감한 계산 정보는 제외해 주세요.

곱셈: * 또는 ×를 직접 입력합니다. 2(3+4)는 지원하지 않습니다.
거듭제곱과 XOR: **는 거듭제곱, ^는 비트 XOR입니다.
선행 0: 010은 8진수 8입니다. 십진수 10은 10으로 입력합니다. 08과 09는 잘못된 8진수 입력입니다.
백분율: %는 나머지입니다. 200의 15%는 200*15/100으로 계산합니다.
각도: 계산 메뉴에서 RAD 또는 DEG를 선택합니다. 역삼각함수도 같은 단위를 사용합니다.
언어: SpeedCalc → 언어에서 시스템 설정 따르기, 한국어, English를 선택합니다.
글꼴: 설치된 기본 목록과 활성 사용자 설치 글꼴을 설정에서 선택합니다. 저장된 글꼴이 없으면 시스템 고정폭으로 대체합니다.
정밀도: ≈는 표시 반올림입니다. 표시 설정은 실제 계산값을 바꾸지 않습니다.
저장 안내: 상태 글자에 마우스를 올리면 원인을 확인할 수 있습니다. ⌘S로 기록을 별도 내보낼 수 있습니다. 저장된 세션을 읽지 못하면 원본을 보존하고 자동 저장을 중지합니다.

계산 기록, 변수, 설정은 로컬에 저장합니다. 기록 지우기는 변수와 최근 결과 참조를 유지합니다.

SpeedCalc Support
Expression calculator for Mac · macOS 13 or later

Contact: bobaepapa@gmail.com
Include your SpeedCalc version, macOS version, the expression and steps to reproduce the issue. Remove sensitive calculation data before sending.

Multiplication: Use * or × explicitly; 2(3+4) is not supported.
Powers and XOR: ** means power; ^ means bitwise XOR.
Leading zero: 010 is octal 8. Use 10 for decimal ten. 08 and 09 are invalid octal input.
Percent: % is remainder, not percentage. For 15% of 200, enter 200*15/100.
Angles: Choose RAD or DEG in Calculation. Inverse trig functions use the same unit.
Language: SpeedCalc > Language offers Follow System, 한국어 and English.
Fonts: Installed built-in selections and active user-installed fonts appear in Settings. A missing saved font falls back to system monospaced.
Precision: ≈ indicates display rounding; the stored calculation value is not changed by display settings.
Save warning: Hover over the status text for details. Export History (Command+S) saves a separate copy. If a saved session cannot be read, the original is preserved and auto-save stops.

Calculation history, variables and settings are stored locally. Clearing history keeps variables and recent result references.
